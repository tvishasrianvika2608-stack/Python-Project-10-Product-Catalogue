# Project 10: Tuple-Based Product Catalogue Audit

## Problem Description
This project stores product identifiers, prices, and stock quantities using tuples. It detects invalid product records, calculates the total inventory value, and identifies products that require replenishment based on their available stock.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Tuples and tuple operations
- Lists
- For loops
- Conditional statements (if, else)
- Arithmetic operators
- User input and output

## Files Included
- `Question_10_Product_Catalogue.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the product ID, price, and stock quantity for four products.
5. View the product catalogue audit report.

## Conclusion
The program audits product records, identifies invalid entries, calculates the total inventory value, and displays products that require stock replenishment.
